Eventos de navegación

Describen cómo el usuario y el navegador se mueven: clics, envíos, historial, ciclo de vida de la página, desplazamiento y tamaño de la ventana.

click

click0
PointerEvent Burbujea: sí Cancelable: sí

Se dispara al presionar y soltar el botón principal sobre un elemento, o al activar un botón con Enter o Espacio. Como burbujea, un solo listener en el contenedor atiende a todos sus hijos (delegación de eventos): target es quien recibió el clic y currentTarget quien tiene el listener.

Haz clic en cualquier parte del recuadro

Último evento

Aún no se ha disparado.
Ver código 
const demo = document.getElementById("click-demo");

// Un solo listener atiende a todos los hijos (delegación)
demo.addEventListener("click", (event) => {
  console.log(event.target);        // el elemento exacto donde se hizo clic
  console.log(event.currentTarget); // el elemento que tiene el listener
  console.log(event.clientX, event.clientY, event.detail);
});

submit

submit0
SubmitEvent Burbujea: sí Cancelable: sí Objetivo: <form>

Se dispara en el <form> al enviarlo (botón submit o Enter) y solo si pasó la validación. Por defecto el navegador navega a la URL de action y recarga la página; preventDefault() lo evita para que lo manejes con JavaScript.

Escribe algo y presiona Enter

Con el interruptor apagado la página se recarga y verás ?q=… en la URL. El registro se conserva.

Último evento

Aún no se ha disparado.
Ver código 
const form = document.getElementById("nav-form");

form.addEventListener("submit", (event) => {
  event.preventDefault();                 // sin esto, la página se recarga
  const q = new FormData(form).get("q");
  console.log("Buscando:", q);
});

hashchange

hashchange0
HashChangeEvent Burbujea: no Cancelable: no Objetivo: window

Se dispara en window cuando cambia el #fragmento de la URL: por un enlace <a href="#…">, por location.hash o por los botones atrás/adelante. Es la base de los routers más simples de una SPA. Trae oldURL y newURL.

Navegar a un #fragmento también dispara popstate, justo antes de hashchange. Míralo en el registro y en la tarjeta de popstate.

popstate

popstate0

DOMContentLoaded

DOMContentLoaded0
Event Burbujea: sí Cancelable: no Objetivo: document

Se dispara en document cuando el HTML ya se leyó y el árbol DOM está construido, sin esperar hojas de estilo, imágenes ni subframes. Es el momento seguro para usar getElementById o querySelector. Si el script va al final del <body> o usa defer, no lo necesitas.

Ocurre una sola vez, al cargar: recarga la página para verlo de nuevo en el registro.

beforeunload

beforeunload0
BeforeUnloadEvent Burbujea: no Cancelable: sí Objetivo: window

Se dispara en window justo antes de cerrar o recargar la pestaña, o de salir hacia otra página. Si el listener llama a preventDefault(), el navegador pide confirmación. Úsalo solo para proteger cambios sin guardar.

El texto del aviso es fijo (los navegadores ignoran el personalizado) y solo aparece si hubo interacción previa con la página.

Desarmado: no hay listener registrado.

Salir a MDN

Último evento

Aún no se ha disparado.
Ver código 
function warnBeforeLeaving(event) {
  event.preventDefault();   // pide confirmación al navegador
  event.returnValue = "";   // algunos navegadores lo exigen
}

toggle.addEventListener("change", () => {
  if (toggle.checked) {
    window.addEventListener("beforeunload", warnBeforeLeaving);
  } else {
    window.removeEventListener("beforeunload", warnBeforeLeaving);
  }
});

focus / blur

focus0 blur0
FocusEvent Burbujea: no Cancelable: no

focus llega cuando un elemento recibe el foco (clic, Tab o .focus()) y blur cuando lo pierde. Ninguno burbujea: para delegar usa focusin/focusout o escucha en fase de captura (true). relatedTarget indica el otro elemento involucrado.

Campo con foco: ninguno · usa Tab y clic.

Último evento

Aún no se ha disparado.
Ver código 
// focus y blur NO burbujean: se capturan con el tercer argumento (true)
form.addEventListener("focus", (event) => {
  event.target.closest(".field").classList.add("is-focused");
}, true);

form.addEventListener("blur", (event) => {
  event.target.closest(".field").classList.remove("is-focused");
  console.log("Pasa el foco a:", event.relatedTarget);
}, true);

submit

submit0
SubmitEvent Burbujea: sí Cancelable: sí Objetivo: <form>

Aquí submit sirve para leer los datos: new FormData(form) recoge todos los campos con name, y event.submitter dice cuál botón envió el formulario. Si un campo no cumple la validación (required, type="email"…), submit no se dispara.

Los datos enviados aparecerán aquí.

Último evento

Aún no se ha disparado.
Ver código 
form.addEventListener("submit", (event) => {
  event.preventDefault();

  // El segundo argumento incluye el botón que envió el formulario
  const data = Object.fromEntries(new FormData(form, event.submitter));
  console.log(data);   // { name: "Ana", email: "...", action: "save" }

  if (event.submitter.value === "new") form.reset();
});

dragstart / dragover / drop

dragstart0 dragover0 drop0
DragEvent Burbujea: sí Cancelable: sí

dragstart se dispara en el elemento draggable="true" al empezar a arrastrarlo; ahí se guarda el dato con dataTransfer.setData(). dragover se repite sobre el destino mientras el puntero está encima. drop ocurre al soltar y es donde se lee el dato con getData().
